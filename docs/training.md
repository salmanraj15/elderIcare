# elderIcare Training

## Overview

The elderIcare training pipeline is implemented in:

```text

src/eldericare/train.py

```

The training module provides utilities for:

- Training the acoustic event classifier

- Evaluating overall classification accuracy

- Evaluating per-class accuracy

- Saving the trained baseline model

The current training workflow uses the synthetic development dataset.

## Training Dataset

The current development dataset is generated by:

```text

create_synthetic_dataset()

```

from:

```text

src/eldericare/dataset.py

```

The synthetic dataset contains three acoustic classes:

- `background`

- `speech`

- `impact`

The dataset is intended for development and testing.

It is not representative of real-world elder-care acoustic environments.

## Dataset Splitting

The dataset can be divided into training and evaluation sets using:

```text

split_dataset()

```

The split is:

- Deterministic when the same seed is used

- Stratified by class

- Controlled using an evaluation fraction

The current training script uses:

```text

evaluation_fraction=0.2

seed=42

```

This means approximately 20% of each class is assigned to the evaluation set.

## Model

The model used for training is:

```text

AcousticEventClassifier

```

The model is implemented in:

```text

src/eldericare/model.py

```

The current model accepts two input features:

- RMS energy

- Peak amplitude

It produces three output classes:

- `background`

- `speech`

- `impact`

## Training Configuration

The current default training configuration is:

- Epochs: `50`

- Batch size: `32`

- Learning rate: `0.01`

The training process uses:

- PyTorch

- Cross-entropy loss

- Adam optimizer

## Training Process

The training workflow is:

```text

Synthetic dataset

↓

Train/evaluation split

↓

AcousticEventClassifier

↓

Training batches

↓

Forward pass

↓

Cross-entropy loss

↓

Backpropagation

↓

Adam optimizer

↓

Trained model

```

The model is placed into training mode before the training loop begins.

For each batch:

1. Gradients are cleared.

2. Features are passed through the model.

3. Classification loss is calculated.

4. Gradients are calculated using backpropagation.

5. The optimizer updates the model parameters.

## Evaluation

The training module provides overall accuracy evaluation.

The evaluation process:

```text

Evaluation dataset

↓

Model predictions

↓

Predicted class

↓

Compare with labels

↓

Calculate accuracy

```

Overall accuracy is calculated as:

```text

correct predictions / total predictions

```

Per-class accuracy is also available.

This reports a separate accuracy value for:

- `background`

- `speech`

- `impact`

## Running Training

The training module can be executed directly using:

```powershell

python -m eldericare.train

```

The current training script:

- Creates the synthetic dataset.

- Splits the dataset into training and evaluation sets.

- Trains the classifier.

- Evaluates the model.

- Reports overall accuracy.

- Reports per-class accuracy.

- Saves the trained model.

Example output:

```text

Evaluation accuracy: 100.00%

background: 100.00%

speech: 100.00%

impact: 100.00%

Model saved to: models\baseline.pt

```

The exact accuracy may change if the dataset, model, training configuration, or random seed changes.

## Model Output

The trained model is saved to:

```text

models/baseline.pt

```

The model file contains the trained model parameters.

Model artifacts are excluded from Git using:

```text

*.pt

*.pth

*.onnx

*.tflite

```

## Testing

The training functionality is covered by automated tests.

The tests verify:

- The training function returns a classifier.

- The trained model can predict synthetic data.

- Overall evaluation accuracy is valid.

- Per-class evaluation returns valid accuracy values.

Run the complete test suite with:

```powershell

python -m pytest -v

```

All tests should pass before changes are integrated into the main workflow.

## Current Results

The current synthetic development pipeline has passed the project's automated training and evaluation tests.

The training script has also produced a baseline model with successful evaluation on the synthetic evaluation dataset.

These results should not be interpreted as evidence of real-world model performance.

## Limitations

The current training process has several limitations:

- It uses a synthetic dataset.

- The dataset is not representative of real-world elder-care environments.

- Only two simple audio features are currently used.

- Only three acoustic event classes are currently supported by the model.

- Real-world generalization has not been established.

- No production audio dataset is currently used.

Synthetic-dataset accuracy should therefore not be presented as real-world accuracy.
